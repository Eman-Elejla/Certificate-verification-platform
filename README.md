# CertiChain – Blockchain-Based Certificate Verification System

CertiChain is a blockchain-based platform designed to issue, store, and verify academic certificates securely using Smart Contracts.

The platform allows universities to issue digital certificates and enables users to verify their authenticity by uploading the original certificate file.

Each certificate is identified by its unique SHA-256 cryptographic hash, which is used to verify the integrity and authenticity of the document.

##  Features

###  Certificate Issuance
- Issue digital academic certificates through a university dashboard.
- Store certificate information on the blockchain using Smart Contracts.
- Generate a unique SHA-256 hash for each certificate.
- Record student information, course details, and grades.

### 🔍Certificate Verification
- Upload a certificate in PDF, PNG, or JPG format.
- Automatically calculate the file's SHA-256 hash.
- Compare the generated hash with the certificate identifier stored on the blockchain.
- Display certificate information if a matching record exists.
- Detect certificates that have not been registered.

###  Blockchain Integration
- Smart Contract-based certificate management.
- Blockchain-backed certificate records.
- Secure and tamper-resistant certificate verification.
- Ethereum local blockchain integration.

###  University Dashboard
- Issue new academic certificates.
- View previously issued certificates.
- Display student information and certificate status.
- Access blockchain certificate records.

### 🖥️ User Interface
- Arabic RTL interface.
- Responsive design using Tailwind CSS.
- Drag-and-drop certificate upload.
- Separate interfaces for certificate verification and university administration.

##  Installation & Setup

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Eman-Elejla/CertiChain.git
```

### 2. Navigate to the Project Directory

```bash
cd CertiChain
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Compile the Smart Contract

```bash
npx hardhat compile
```

This command compiles the Solidity Smart Contract and generates its ABI and artifacts.

### 5. Start the Local Ethereum Network

Open a new terminal and run:

```bash
npx hardhat node
```

The local blockchain will run at:

```text
http://127.0.0.1:8545
```

### 6. Deploy the Smart Contract

Deploy the `CertiChain.sol` contract to the local Hardhat network using your deployment script.

After deployment, copy the contract address and update the `CONTRACT_ADDRESS` variable in `server.js`.

Make sure the backend uses the ABI generated by Hardhat.

### 7. Start the Backend Server

```bash
node server.js
```

The Express server will start at:

```text
http://localhost:3000
```

### 8. Open the Application

Open the following URL in your browser:

```text
http://localhost:3000
```

The frontend is served directly through Express static middleware.

##  API Endpoints

The backend exposes the following REST API endpoints:

### 1. Issue a Certificate

**POST** `/api/issue`

Issues a new certificate through the deployed Smart Contract.

**Request Body:**

```json
{
  "certId": "0x123456789abcdef...",
  "studentName": "Eman Ahmad",
  "courseTitle": "Bachelor of Computer Science",
  "grade": "Excellent"
}
```

**Response:**

```json
{
  "success": true,
  "message": "تم التوثيق بنجاح!"
}
```

### 2. Verify a Certificate

**GET** `/api/verify/:hash`

Verifies a certificate using its SHA-256 hash.

**Example:**

```http
GET /api/verify/0x123456789abcdef...
```

**Successful Response:**

```json
{
  "isValid": true,
  "studentName": "Eman Ahmad",
  "courseTitle": "Bachelor of Computer Science",
  "grade": "Excellent",
  "issueDate": "11/5/2026"
}
```

If the certificate does not exist:

```json
{
  "isValid": false,
  "message": "شهادة غير موجودة"
}
```

### 3. Get All Certificates

**GET** `/api/list`

Retrieves all certificate IDs registered in the Smart Contract and returns their associated information.

**Example:**

```http
GET /api/list
```

**Response:**

```json
[
  {
    "certId": "0x123456789abcdef...",
    "studentName": "Eman Ahmad",
    "courseTitle": "Bachelor of Computer Science",
    "universityId": "N/A",
    "grade": "Excellent",
    "issueDate": "11/5/2026"
  }
]
```

##  How Certificate Verification Works

CertiChain uses SHA-256 hashing to identify and verify certificate files.

The verification process follows these steps:

1. The university uploads the original certificate file.
2. The frontend reads the file and calculates its SHA-256 hash.
3. The hash is submitted to the backend.
4. The backend queries the Smart Contract using the certificate hash.
5. The Smart Contract returns the stored certificate information.
6. The application displays the verification result.

### Verification Workflow

```text
Original Certificate
        |
        v
   File Upload
        |
        v
  SHA-256 Hashing
        |
        v
   Express Backend
        |
        v
   Smart Contract
        |
        v
  Certificate Lookup
        |
        v
  Verification Result
```

## Smart Contract

The `CertiChain.sol` Smart Contract manages certificate records on the Ethereum blockchain.

The backend interacts with the contract through Ethers.js.

The contract integration uses:

- Contract Address
- Contract ABI
- Ethereum JSON-RPC Provider
- Signer
- Smart Contract functions

The main operations include:

- Issuing certificates.
- Retrieving certificate information.
- Retrieving all registered certificate IDs.

##  Project Limitations

This project is currently an educational prototype.

- The current configuration uses a local Hardhat blockchain.
- Certificate files are not stored directly on the blockchain; their hashes are used as identifiers.
- The backend uses a configured local signer.
- The project requires additional security measures before production deployment.
- The contract address must match the deployed Smart Contract.
- The current frontend and backend should be extended to support complete certificate metadata validation.
